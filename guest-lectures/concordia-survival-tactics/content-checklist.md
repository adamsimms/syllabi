# "Gather Your Content" Checklist

[Index](README.md) · [Run-of-show](run-of-show.md) · [Slides](slide-outline.md) · [Sitemap](sitemap-worksheet.md) · **Checklist** · [File formats](file-formats.md) · [IG grid](instagram-grid-template.md)

Collect all of this in one folder *before* building.

## Writing
- [ ] **Artist statement** — ~150–300 words (what the work is / how / why).
- [ ] **Short bio** — ~40–60 words, third person.
- [ ] **Long bio** — ~150–250 words, third person.
- [ ] **Per-project statement** — one short paragraph per project.
- [ ] **Project metadata** — title, year, medium, dimensions/duration for each work.

## Visuals
- [ ] **Work documentation** — clean, consistent shots of every piece (or video stills / install shots).
- [ ] **Portrait / headshot** (optional, useful for bios & press).
- [ ] Files exported for web: longest edge ~2000–2560px, sRGB, JPEG (photos) / PNG (graphics/transparency), sensible filenames (`lastname_projecttitle_01.jpg`).
- [ ] **Alt text** drafted for key images.

## Video / time-based work
- [ ] **Full-quality source exports** kept, plus web versions: MP4 (H.264), 1080p is plenty for web.
- [ ] **Uploaded to Vimeo or YouTube** (don't self-host large files) — set privacy/password as needed; grab the embed link.
- [ ] **Captions/subtitles** where relevant; a **still frame** chosen as the poster/thumbnail.
- [ ] Decide playback intent per piece: muted autoplay loop vs. click-to-play with sound.

## Style kit (keep it consistent everywhere)
- [ ] **One headshot** you reuse across site + social + press.
- [ ] **One bio voice** (see above) reused across platforms.
- [ ] **Colour palette** — 2–4 colours. Build one with [Coolors](https://coolors.co), or extract it from your own artwork with [Adobe Color → Extract Theme](https://color.adobe.com). Optional preview: [Realtime Colors](https://realtimecolors.com).
- [ ] **One type pairing** (a heading + body font that read well together).

## Professional
- [ ] **CV** (current) — PDF + copy-paste text.
- [ ] **Contact email** (professional address; set up domain email forwarding if you have a domain).
- [ ] **Links** — social handles, representation, press.
- [ ] **Domain name** idea(s) — check availability (~$12/yr).
- [ ] **Backups** — keep your own copy of every image + your written content; export your site periodically. Platforms die; your archive shouldn't.
