[Index](README.md) · [Run-of-show](run-of-show.md) · [Slides](slide-outline.md) · **Sitemap** · [Checklist](content-checklist.md) · [File formats](file-formats.md) · [IG grid](instagram-grid-template.md)

**How to use:** sketch boxes and arrows before touching any builder. Start from this common structure, then cut/add to fit your work.

```
HOME  (landing — sets the tone; often a single strong image or an index of projects)
│
├── WORK / PROJECTS  (the core)
│     ├── Project A ──> images/video + project statement + year, medium, dimensions
│     ├── Project B ──> …
│     └── Project C ──> …
│
├── ABOUT  (long bio + artist statement + optional portrait)
│
├── CV  (on-page and/or downloadable PDF)
│
└── CONTACT  (email; social links; representation/press if any; optional mailing-list signup)
```

## Decision prompts
- Single-scroll or multi-page? Projects as a grid or a sequence?
- What's the *first thing* a visitor sees — an image, a name, an index?
- How should someone move through the work — do you control the order, or do they?
- What can you leave OUT? (Restraint reads as confidence.)
