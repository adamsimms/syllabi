## Specs (verify live — platforms change)
- **Feed uploads:** portrait **4:5 = 1080×1350 px** (recommended — most space, matches current grid crop). Square 1:1 = 1080×1080. Landscape 1.91:1 = 1080×566.
- **Profile grid:** as of 2025 the grid displays **4:5 portrait** tiles, 3 across — upload at 4:5 so previews aren't cropped.
- **Stories / Reels:** 9:16 = 1080×1920.
- **Format:** JPEG, sRGB for stills. Upload high quality — IG re-compresses.
- **Video / Reels:** MP4 (H.264), 9:16 vertical, keep it short; add captions (many watch muted); a strong first frame = your thumbnail.

## Grid planner (think in rows of 3)

```
Row 1:  [  1  ] [  2  ] [  3  ]
Row 2:  [  4  ] [  5  ] [  6  ]
Row 3:  [  7  ] [  8  ] [  9  ]

Post ideas / rhythm:
1 ___________   4 ___________   7 ___________
2 ___________   5 ___________   8 ___________
3 ___________   6 ___________   9 ___________
```

- Plan a **visual rhythm** (e.g., work / detail / text; or alternating tones) so the grid reads as a composition, not a pile.
- Draft in a 3-wide layout (Notes, a slides file, or a planner app) before posting.

## Bio / link structure
- **Name field** = searchable keywords (e.g., "Jane Doe — Sculpture").
- **Bio** = one-line practice description + location + a call to action.
- **Link** = your website (use a link-in-bio hub only if you truly have multiple destinations — otherwise send them straight to your site).
- **Cross-link both ways:** site links to social, social links to site.
